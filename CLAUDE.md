## Project

Arcade Vault: online game platform where users compete for points. Early-stage (only the Create Next App scaffold exists in `app/`).

## Commands

- `npm run dev` — dev server (Turbopack)
- `npm run build` / `npm start` — production build / serve
- `npm run lint` — ESLint (flat config, `eslint.config.mjs`)
- No test runner configured yet.

## Next.js 16 warning

Next 16.4.6 / React 19.3 — differs from training data. Before writing code, read the relevant guide in `node_modules/next/dist/docs/` (`01-app`, `02-pages`, `03-architecture`, `04-community`; start at `index.md`). App Router only (`app/`).

`next.config.ts` enables non-default features: `cacheComponents: true`, `partialPrefetching: true`, `experimental.agentFeedback`. Cache Components changes data-fetching/caching semantics — check docs before fetching data or using dynamic APIs.

## Styling

Tailwind 4 wired via Turbopack loader (`@tailwindcss/turbopack` rule for `*.css` in `next.config.ts`), not PostCSS. Styles in `app/globals.css`.
